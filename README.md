# 診断士1次トレーナー v8

中小企業診断士 第1次試験の学習アプリ（PWA）。ホーム画面に追加すると、全画面・オフラインで動きます。

このアプリの目標は「やりきれば第1次試験に合格する水準に届く」ことです。その担保のしかたと、いまどこまで届いているかを、このREADMEに数字で記録していきます。

## 合格水準の担保のしかた

1. **範囲**：公式の出題範囲の全細目と、過去10年の出題論点を論点表にまとめ、全細目に演習問題とテキストを用意する。網羅率をこのREADMEに数字で出す。
2. **形式**：本試験と同じ形式（○×の肢別演習に加え、単答・組み合わせ・空欄補充・計算・図表の読み取り）。科目別の模試は本番と同じ時間・問題数・配点。
3. **水準**：「すべて」「必ず」など極端な言い回しや常識で解ける肢を除き、要件・数値・主体などを1か所だけ誤らせる本試験の水準にそろえる。正反対の選択肢を並べない。正答の位置を散らす。
4. **正確性**：法令は試験の基準日（令和8年度は5月1日）に施行されている条文、白書は出題対象の年版、会計基準・統計は一次資料と照合する。計算問題はプログラムで検算する。作成とは別の担当が一次資料と照合して検証し、最後の抜き取りで正答の誤り0件を確認する。
5. **到達判定**：「完了」は問題を解き終えたことではなく、公式の過去問で合格点を安定して取れたことで判定する。
   - 練習：公式過去問で、最後に解いた2つの年度がどちらも60点以上
   - 初見：仕上げ用の令和8年度・令和7年度を初めて解いて60点以上
   - 本試験の合格基準（合計420点以上かつ40点未満なし）より厳しく、全科目60点以上を条件にする

## 主な機能

- 今日：復習と新しい問題（間隔反復 FSRS-4.5）、学習タイマー、週の学習時間、次にやること
- 学習：公式の出題範囲にそった論点表と網羅率、論点ごとのテキスト、科目別・論点別の演習、誤りの報告
- 過去問：公式の正解と配点による自動採点（制限時間タイマーつき）、仕上げ用年度の取り置き
- 判定：科目ごとの完了判定、直近の得点による本試験の試算
- 記録：週ごとの学習時間、設定、学習記録の書き出し・読み込み

## ファイル構成

```
├── index.html
├── sw.js            ← オフライン用（版管理つきキャッシュ）
├── manifest.json
├── .nojekyll
├── README.md
├── icons/icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
└── data/
    ├── syllabus.json   ← 論点表（公式の出題範囲）
    ├── past.json       ← 過去問の正解・配点と問題PDFのリンク
    ├── q_<科目>.json   ← 演習問題（keizai, zaimu, kigyo, unei, homu, joho, chusho）
    └── t_<科目>.json   ← テキスト（t_kigyo.json, t_unei.json, t_zaimu.json）
```

## 更新のしかた

1. 上の構成どおりにファイルを置き換える（JSON は必ず `data/` の中）。
2. `index.html` の `APP_VER` と `sw.js` の `VER` は同じ値にする。値を上げると、各端末のキャッシュが新しい版に入れ替わる。

## 技術メモ

- Vanilla JS（フレームワークなし）・フォントは Noto Sans JP
- 学習記録は各端末のブラウザ（localStorage）に保存。機種変更の前に「記録」タブから書き出す
- 外部へのデータ送信はなし
- 過去問の問題文はアプリに収録しない（著作権）。公式PDFへのリンクと、正解・配点のみを収録
